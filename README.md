# قرايتي — فضاء التعلّم ديالك

موقع تعليمي تجريبي بالدارجة المغربية، فيه أدوات بسيطة لتنظيم القراية، تلخيص نص الدرس بطريقة محلية، وترتيب خطوات التفكير فالتمارين.

## كيفاش تشغلو؟

ما كاين لا build لا dependencies. حل `index.html` مباشرة فالمتصفح، أو شغّل خادم محلي بسيط:

```bash
python3 -m http.server 8000
```

ومن بعد دخل لـ `http://localhost:8000`.

## شنو كاين فهاد النسخة؟

- واجهة متجاوبة مع الهاتف والحاسوب، وبالدارجة المغربية.
- تلخيص أولي كيرتب بعض الجمل المهمة؛ ماشي ذكاء اصطناعي ولا بديل على مراجعة الدرس.
- مساعد كيحول نص التمرين لخطة عامة ديال التفكير؛ ما كيحسبش حلول دقيقة وما كيضمنش جواب صحيح.
- مخطط مهام بسيط، ومحفوظات محلية باستعمال `localStorage`.
- البيانات كاتبقى فالمتصفح ديالك؛ ما كاينش تسجيل دخول ولا backend فهاد النسخة.

## نشره مع GitHub Pages

من إعدادات المستودع، اختار **Settings → Pages**، ومن بعد النشر من الفرع `main` والمجلد `/ (root)`. هاد الموقع static وما كيحتاجش خطوة build.

## الخطوات الجاية المقترحة

إلى بغيتي تخليه منصة كاملة للطلبة، خاص تزيد backend آمن، حسابات المستخدمين، قاعدة بيانات، دعم حقيقي للمواد والمستويات، وواجهة ذكاء اصطناعي عبر API محفوظة فالسيرفر (ماشي فـ JavaScript ديال المتصفح). خاص كذلك تجريب الدقة مع الأساتذة والطلبة، وحماية البيانات قبل نشر هاد الميزات.
